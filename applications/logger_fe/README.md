# logger_fe

采集软件 Logger 前端代码

## 说明(Description)

使用 vue3.0 框架,参考[vite](https://vitejs.dev/guide/#trying-vite-online)官方教程创建 vue-ts 项目;
构建 vite + vue + ts + vue-router + pinia 项目

## 先决条件(Prerequisites)

- vue3.0

## 特点(Features)

- 实现了采集及其配置,采集设备维护,采集可视化等主要功能;
- 实现了采集过程打标签,标签维护等相关功能;
- 使用 http 请求进行用户操作与服务器的交互;
- 使用 websocket 实现了实时监测功能;

## 工程化(Run)

- 运行: `npm run dev` 启动项目
- 打包: `npm run build` 打包项目为静态资源
